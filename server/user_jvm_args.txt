# Memory for the server. 8G is safe anywhere; on a PC with 32 GB or more use 10G.
# More than 12G doesn't help: only about 2.5 GB is still in use after a collection.
# Keep -Xms equal to -Xmx so Java reserves it all at start (no resizing stalls).
# On Exaroton you set RAM in the web panel instead and this file isn't used.
# Why these flags and the alternatives that were benchmarked: docs/java-flags.md
-Xms8G
-Xmx8G
# G1 garbage collector settings (Aikar's flags). Best tick speed and chunk generation in the pack's benchmark.
-XX:+UseG1GC
-XX:+ParallelRefProcEnabled
-XX:MaxGCPauseMillis=200
-XX:+UnlockExperimentalVMOptions
-XX:+DisableExplicitGC
-XX:+AlwaysPreTouch
-XX:G1NewSizePercent=30
-XX:G1MaxNewSizePercent=40
-XX:G1HeapRegionSize=8M
-XX:G1ReservePercent=20
-XX:G1HeapWastePercent=5
-XX:G1MixedGCCountTarget=4
-XX:InitiatingHeapOccupancyPercent=15
-XX:G1MixedGCLiveThresholdPercent=90
-XX:SurvivorRatio=32
-XX:+PerfDisableSharedMem
-XX:MaxTenuringThreshold=1
