# Home, Storage and Maps (home)

## home/storage | Backpacks and Storage
- Sophisticated Backpacks and Sophisticated Storage: containers customised with upgrades (same upgrade system). Backpacks go on your back; Storage = chests, barrels, shulker boxes. Open backpack with J (pack's key).
- Backpack [sophisticatedbackpacks:backpack]: worn on back. Tiers: basic, copper, iron, gold, diamond, netherite; each more slots and upgrade slots.
- Storage Chests [sophisticatedstorage:chest]: chests, barrels, shulker boxes in same material tiers. Barrels can be limited to a few stacks. Storage Tool changes appearance.
- Stack Upgrade [sophisticatedbackpacks:stack_upgrade_tier_1]: multiplies items per slot; higher tiers stack more; conversion recipes upgrade one tier to the next.
- Common upgrades: Pickup and Magnet collect items (range 2, Advanced 4); Filter limits what goes in; Feeding eats for you; Restock and Refill keep hotbar full; Void and Compacting tidy overflow; Everlasting makes a backpack on the ground immune to fire, lava and the void; Smelting, crafting and more.
- Controller [sophisticatedstorage:controller]: links many nearby Sophisticated chests and barrels into one big inventory. Add a Storage Link to connect other storage.
- Both mods have Create add-ons: backpacks and storage ride on contraptions with upgrades. Backpacks on contraptions use the official Sophisticated Backpacks Create Integration. See Contraptions (see create_basics/contraptions).
- More: Inventory Tools (see home/inventory_tools)

## home/inventory_tools | Inventory Tools
- Client-side helpers: Inventory Profiles Next (sorts, moves items), Mouse Tweaks (faster mouse use), Shulker Box Tooltip (previews contents). Settings in the Mods menu.
- Inventory Profiles Next [minecraft:hopper]: sorts with a button or key, moves matching stacks, locks slots. Auto-refill is OFF in this pack; turn on in its config (see glossary/config) screen.
- Shulker Box Tooltip [minecraft:shulker_box]: hover a shulker box to see contents.
- Mouse Tweaks: drag-split (hold click, drag over slots to spread a stack); scroll wheel over a slot moves items between inventories.
- Containers: Storage (see home/storage).

## home/building | Furniture and Decor
- Non-Create building mods: Handcrafted (furniture), Macaw's (doors, roofs, windows), Supplementaries (many small useful blocks). Create-flavoured decor: Create Decor (see home/create_decor).
- Handcrafted [handcrafted:oak_table]: tables, benches, couches, desks, drawers, shelves, counters, beds, sheets, cushions in many wood types; trophies and pillar trims.
- Macaw's Roofs [mcwroofs:oak_roof]: many roof shapes (attic, top and lower base roofs per wood and material); Roofing Hammer helps. Macaw's Doors and Windows follow same pattern.
- Macaw's Windows [mcwwindows:oak_window]: resizeable windows, Window Hammer, Window Key. Macaw's Doors: many door styles, Garage Remote.
- Supplementaries [supplementaries:jar]: jars hold small things; flags, awnings, bunting, candle holders, goblets, book piles, soap, a Wrench. Browse item list in JEI (see start_here/tools).
- Furniture is mostly decor. Seats on moving contraptions (see create_basics/contraptions): Create's own Seat works; Coasters (see transport/coasters) add coaster seats.
- Cafe-style decor: Cozy Cafe (see food/cozy_cafe).

## home/create_decor | Create Decor
- Mods adding blocks that suit Create machines; most purely decorative, a few change how Create builds.
- Create Deco [createdeco:brass_coinstack]: metal and brick decor: catwalks, bars, cage lamps, coin stacks, shipping containers, train hulls. Bricks in several colours and cracked/tiled forms.
- Design n' Decor [dndecor:brown_industrial_cogwheel]: industrial set dressing: sheet metal, large metal girders, containers, large fans, bolts, display boards, many colours.
- Copycats+ [copycats:copycat_block]: copycat (see glossary/copycat) blocks take the look of any block applied: slices, layers, doors, fences, plates, cogwheels, shafts. Replaces the copycats Create: Connected has switched off.
- Create: Framed [createframed:cyan_stained_framed_glass]: framed and tiled stained glass, cardboard blocks, peephole panes; many colours and connected-texture variants.
- Create Encased [createcasing:brass_encased_andesite_large_cogwheel]: more casings (see glossary/encased) for shafts, cogwheels, pipes, gearboxes. Pure variety; same function as Create's own.
- Create: Connected [create_connected:six_way_gearbox]: functional blocks: six-way gearbox, clutches, kinetic bridge and battery, fan catalysts (see glossary/fan_catalyst). Its own copycats are off; old ones migrate to Copycats+.
- Related: Furniture and Decor (see home/building), Transmission (see create_basics/transmission)

## home/maps | Maps and Waypoints
- Xaero's Minimap and World Map are the navigation: small map on screen; full-screen map shows everywhere explored. Maps drawn and saved on your own PC. Server has a copy of both mods too, so each world and dimension keeps its own map.
- Xaero's Maps [minecraft:filled_map]: waypoints can be set from either map. Right-click world map for options (temporary waypoint, sharing a location in chat). Zoom minimap in its settings.
- Death Points [minecraft:recovery_compass]: dying makes a Latest Death waypoint; older deaths can be kept. Tune in minimap settings.
- Waypoint names can be shared to chat so teammates add them. Watch out: don't expose a secret base.
- Keybinds: Controls, under Xaero categories. Open settings from the minimap or Mods menu.
- Trains and Airships [minecraft:compass]: Xaero Train Map shows Create train lines and stations on the world map. Create - Xaero's map draws Sable (see glossary/sub_level)-based vehicles like airships live, with rotation. (see transport/trains) (see flight/airships)
- Create Railways Navigator: Navigator item and Advanced Display boards for stations, to plan and show train routes. Its overlay options key is \ (backslash) here.
- Long trips by air or sea: Destinations (see flight/destinations).

## home/guide_shelf | Guide Shelf
- Guide Shelf puts buttons in the inventory screen for every in-game guide book, this Field Guide included. Open a guide without holding the book; handy for mods with their own handbook.
  - shows item minecraft:bookshelf
- You also get this book on first join; craft from a Book and Andesite (shapeless); JEI (see start_here/tools) can open it.
- Mods like Create keep help in Ponder (see glossary/ponder): hold W over an item.
- Start: Welcome (see start_here/welcome).

## home/starter_kit | Starter Kit and Helpers
- Starter Kit gives new players configurable (see glossary/config) starter gear on first join; contents depend on the pack's settings. Check inventory on first join to see. Crafting Tweaks and Searchables are small interface helpers.
- Crafting Tweaks [minecraft:crafting_table]: buttons beside crafting grids: rotate, clear, balance, spread items, compress/decompress stacks. Each also has a key in Controls.
- Searchables [minecraft:writable_book]: library adding search bars with autocomplete to other mods' lists; you may only notice a search box inside another screen.
- Other tools: Tools (see start_here/tools). Related: Inventory Tools (see home/inventory_tools).
